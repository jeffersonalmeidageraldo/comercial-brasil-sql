# Comercial Brasil — Análise de Dados com SQL

## Sobre o projeto

Projeto prático de análise de dados utilizando SQL e PostgreSQL, desenvolvido a partir de um cenário comercial fictício.

O objetivo é aplicar conhecimentos de bancos de dados relacionais para transformar registros de clientes em informações úteis para a tomada de decisões empresariais.

## Tecnologias utilizadas

- PostgreSQL
- SQL
- DBeaver
- GitHub

## Competências praticadas

- Criação de bancos de dados
- Criação de tabelas
- Inserção de registros
- Consultas SQL
- Filtragem de dados com WHERE
- Operadores lógicos AND e OR
- Ordenação com ORDER BY
- Função de agregação COUNT
- Agrupamento com GROUP BY
- Filtragem de grupos com HAVING
- Utilização de aliases com AS

## Análises desenvolvidas

- Quantidade total de clientes cadastrados.
- Distribuição de clientes por cidade.
- Identificação de cidades com maior quantidade de clientes.
- Consultas por período de cadastro.
- Evolução diária de novos clientes.
- Identificação de dias com múltiplos cadastros.

## Resultados iniciais

A base de dados contém seis clientes fictícios, distribuídos em quatro cidades de Minas Gerais.

| Cidade | Quantidade de clientes |
|---|---:|
| Itabirito | 2 |
| Mariana | 2 |
| Ouro Preto | 1 |
| Belo Horizonte | 1 |
| Total | 6 |
